Frontend Changer

Rebrand any frontend — change name, images, API URLs & keys in one click

1 Project ZIP

Supports React, Next.js, Vue, plain HTML, etc. Max 100 MB.

2 Change Config (JSON)

• oldAppName → appName (titles, package.json, etc.)
• oldApiBaseUrl → apiBaseUrl
• oldApiKey → apiKey
• images maps uploaded filename → target filename in project
• replacements = extra find/replace pairs

3 New Images (optional)

Filename should match the key in config.images (e.g. logo.png)
